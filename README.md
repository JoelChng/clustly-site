# Clustly homepage (static replica)

A static snapshot of the [clustly.ai](https://www.clustly.ai/) homepage, rebuilt from the [Wayback Machine capture on 6 June 2026](https://web.archive.org/web/20260606051635/https://clustly.ai/) (CSS and images filled in from the 9 May 2026 capture, which archived the same visual design).

This is the marketing homepage only. In-app routes such as `/marketplace`, `/tasks/new`, and `/docs` are not included and will 404 until the application is hosted again.
